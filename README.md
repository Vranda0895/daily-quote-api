# Daily Quote API ☁️

A simple serverless API that returns a randomly selected motivational quote in JSON format.

The API is built using Node.js and deployed as a serverless function on Vercel.

---

## Features

- Returns a random quote on every request.
- Returns the quote and author in JSON format.
- Serverless backend using Vercel.
- Publicly accessible HTTP API.
- Easy to test using a web browser or API client.
- Lightweight and beginner-friendly implementation.

---

## Technology Stack

- **Backend:** Node.js
- **API:** Serverless Function
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
- **Data Format:** JSON
